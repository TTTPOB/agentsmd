## Task Model Routing

- Route exploration, research, and simple implementation tasks to the cheap tier.
- Route complicated implementation and reasoning tasks to the mid tier.
- Route broad, high-risk, or difficult cross-module tasks to the expensive tier.
- Follow a model or reasoning level explicitly requested by the user.
- the task_modes tool only accept precise keyword based query, not natural language. so use word like `luna`, `flash`, `deepseek` instead of `openai luna model with xhigh effort`
